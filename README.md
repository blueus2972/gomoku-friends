# 오목 대결! · 다섯 알의 한판

참고 사이트: https://flat-snowflake-1905.anik0327.workers.dev/

참고 화면의 따뜻한 크림색, 나무 바둑판, 큰 색상 버튼과 놀이 흐름을 바탕으로 새로 구현했습니다. 원본 코드·이미지·폰트는 복사하지 않았으며, 캐릭터 그림은 자체 SVG입니다.

## 실행

Node.js 22 이상에서 `npm run dev`를 실행한 뒤 http://127.0.0.1:4174 에 접속하세요. 설치할 외부 패키지는 없습니다. 테스트는 `npm test`입니다.

## 기능

- 15×15 오목판, 같은 기기에서 짝과 대결
- 컴퓨터 초급·중급·고급, 선공 선택
- 초급은 후보 수를 다양하게 선택, 중급은 공격·수비 패턴 평가, 고급은 유력 후보에 상대의 최강 응수를 추가 평가
- 가로·세로·대각선 5개 이상 승리 판정과 승리 줄 표시
- 양쪽 색 모두 이어진 열린 3 두 줄을 금지하고 ×로 표시. 떨어진 3과 4·3 허용. 5개 이상 완성 수는 승리 우선
- 무르기, 다시 시작, 효과음, 승패 집계, 지난 대국 이어하기
- 모바일 대응, 방향키 탐색 및 Enter 착수

정식 렌주 전체 금수 규칙을 적용하지 않는 교육용 오목입니다. 서버·계정·온라인 상대 연결은 필요하지 않습니다. 승패 및 대국은 이 브라우저의 localStorage에만 저장됩니다.

## GitHub 버전 관리

`main` 브랜치의 변경은 GitHub Actions에서 테스트 후 GitHub Pages로 자동 배포됩니다. Pages Source는 GitHub Actions로 설정합니다.

```sh
git add .
git commit -m "변경 내용"
git push
```

안정 버전은 `git tag v1.0.1`과 `git push --tags`로 표시하세요.

파일 구성: `engine.js`는 규칙과 컴퓨터 수 선택, `app.js`는 화면·저장·대국 흐름, `style.css`는 반응형 디자인, `friends.svg`는 첫 화면 캐릭터입니다.
